# CHAOS ARENA

Real-time 2–8 player browser arena. The server owns room state, movement, cooldowns, health, abilities, power-ups, events and win conditions.

## Run
```
npm install
npm start
```
Open http://localhost:8080 in multiple browsers/devices and create/join a room.

This uses a persistent Node.js WebSocket server and needs a WebSocket-capable Node host. Set PORT when required.

Desktop: WASD/arrows, Space for ability. Mobile/tablet: virtual joystick + ability button.
